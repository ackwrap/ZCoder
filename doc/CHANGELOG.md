## 2026-10-28

### ListAgents 同对话任务摘要

- 新增可选 `taskDescription`，仅同对话的非空闲 agent 展示，压缩空白并限制为 200 字符；跨对话始终省略，即使已允许通信也不开放摘要。字段独立于身份信息，不进入消息发送者或审批身份。
- 普通子 agent 复用任务 `description`，停止后续接采用新任务摘要；脚本工作流仅复用明确的任务 `label`。没有独立摘要的主 agent、动态工作流等保持缺省，不截取 prompt、不调用模型生成摘要；空闲或分支切换后不展示旧任务。
- 补充同对话可见性、跨对话隐藏、长度上限、空闲/分支失效与续接更新用例；源码随通信能力提交为 `daa1a0c2`，目录补丁重放通过。未运行功能测试、类型检查或 Lint。

### 项目内 Agent 发现与跨对话通信授权

- 新增 `ListAgents`，返回当前 host 进程内同项目存活 agent 的身份、所属对话与状态，不读取其他对话正文；普通子 agent 和工作流子 agent 均接入。
- 参考 Codex V2 的发现与队列消息语义，`SendMessage` 支持同对话 agent 直接通信，在运行安全点收件，不打断执行或启动空闲 agent；仅原协调者保留续接已停止直属子 agent 的能力。
- 跨对话弹窗提供「仅允许本次」「始终允许向此对话发送消息」「拒绝」。始终允许复用权限存储，严格绑定项目及发送方对话 → 目标对话，不包含反向、其他对话或操作执行权限；未授权路线不被 YOLO、Hook allow 或工具级宽泛 allow 自动放行，显式拒绝仍优先。
- 审批绑定原消息和目标实例，关闭或分支切换后拒绝旧投递；收件队列有界，工作流交互转发到父会话，结束时注销存活身份。同步工具断言并补充发现隔离、消息队列及授权回归用例。
